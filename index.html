Tentang Coding Club

Coding Club adalah tempat untuk mempelajari struktur kebahasaan suatu pemrograman. Banyak bahasa dalam dunia coding salah satunya adalah PHP, JavaScript,Python, CSS, Dsb.

Yang Akan Dipelajari:

  • HTML
  • CSS
  • JavaScript
  • Pemrograman Web
  • Git
  • GitHub

Alur Mengikuti Coding Club:

  1. Mengisi formulir pendaftaran;
  2. Mengikuti pertemuan pertama;
  3. Belajar dasar pemrograman;
  4. Membuat proyek sederhana;
  5. Presentasi hasil proyek;

Kegiatan Coding Club:

Kegiatan 1: Belajar HTML

Untuk belajar HTML dimulai dengan menyiapkan teks editor seperti Visual Studio Code, memahami struktur dasar menggunakan tag dan elemen, serta menampilkan hasilnya di web browser.

Kegiatan 2: Membuat Website

Dalam pembuatan website melibatkan penentuan tujuan, pemilihan domain dan hosting, serta penggunaan platform atau content management system (CMS).

Kegiatan 3: Project Showcase

Mempresentasikan produk, inovasi, atau solusi yang sudah dibuat selama masa belajar.
